# Privacy Policy — Simple WCAG Contrast Checker

Last updated: [tanggal hari ini]

Simple WCAG Contrast Checker does not collect, store, or transmit
any personal data or browsing information.

DATA STORED LOCALLY

- Panel position and size preferences
- Selected WCAG standard (AA or AAA)
- Panel transparency setting

All data is stored locally on your device using Chrome's storage API
and is never sent to any server.

PAGE CONTENT ACCESS
The extension reads the visual properties (color, font size) of
elements on the current page solely to calculate contrast ratios.
This data is processed in-memory and never stored or transmitted.

CLIPBOARD
The extension writes CSS selectors to your clipboard only when you
explicitly click the "Copy" button. No other clipboard access occurs.
